## What I Do

I’m building **[Warmerly](https://warmerly.com)**, an outreach infrastructure platform designed to help businesses manage **email warmup, outbound campaigns, mailbox health, lead data and multi-channel outreach** from one place.

The goal is simple: make outbound infrastructure easier to manage, more reliable and considerably less fragmented.

## 🔥 Building Warmerly

| Product               | What it does                                                                |
| --------------------- | --------------------------------------------------------------------------- |
| **OneMail**           | Warmerly's email infrastructure for managing outbound sending and mailboxes |
| **Email Warmup**      | Builds and maintains mailbox reputation to improve deliverability           |
| **Campaigns**         | Create, manage and automate outbound email campaigns                        |
| **Mailbox Health**    | Monitor sender reputation, inbox placement, spam and bounce performance     |
| **Lead Intelligence** | Email verification, lookup and prospecting tools                            |
| **LinkedIn**          | Outreach and account activity tools for LinkedIn                            |
| **WhatsApp**          | Manage WhatsApp outreach alongside the rest of your campaigns               |

## 🛠 Tech Stack

**Next.js · TypeScript · React · Node.js · PostgreSQL · Redis · Docker · Cloudflare · Azure**

Built with a focus on **performance, scalability, deliverability and automation**.
